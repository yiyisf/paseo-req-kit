# 不做的事

每条一个小节：提议内容、不做的理由、什么情况下会重新考虑。

## 自动合并与部署

流水线只做本地提交。合并、上线由人决定（见 ADR 0005）。重新考虑的条件：有足够可靠的评估数据，并且团队明确要求。

## 远程仓库操作（push、创建 PR）

理由同上。开发同事可以在审阅后自己 push 和创建 PR。

## 跨仓库的需求

一个对话、一条流水线只对应一个仓库目录（见 ADR 0001、0002）。跨仓库的需求请拆成每个仓库各一个需求。

## 在对话中切换工作目录

见 ADR 0002。

## Paseo Hub 多步骤工作流版本

已移到 `legacy/hub-workflow/`，不再维护（见 ADR 0003）。
