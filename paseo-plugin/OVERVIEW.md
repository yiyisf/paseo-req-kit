req-kit 的需求在 Paseo 里的样子：本机所有项目的需求一页看完，哪些在等你确认、哪些卡住了、哪些在运行；点开一个需求，看它走到哪一步、每一步用了多久、质量门的结果，读需求说明、方案、确认预览、提测说明和完成报告。

需要人处理的时候，可以直接在这里确认方案、停止、继续或开始测试验证。这些操作和在终端运行 `req approve`、`req stop`、`req resume`、`req verify` 完全一样，流水线本身不受插件影响；不想让人在网页上操作时，在插件设置中打开"只读"。

还有：侧边栏的"需求"（带待处理数）、每个工作区头部的"需求"按钮和面板、步骤 agent 输入框旁的"需求"按钮，以及使用统计（交付周期、返工、等待、用量）。

需要这台 daemon 上安装 req-kit 1.9 或更新的版本，插件通过本机的 `req api` 读取需求；它不连接任何外部服务。用 `req plugin install` 安装和更新。
