# 汇报幻灯片、海报与社媒

给领导和同事看的材料都按 Bento Launchpad 组织：深色夜空做底，一句大标题，一个视觉主体，一个明确的行动。版式规则与 CMASTER 的"海报与社媒"一致，这里只写 req-kit 的不同之处。

## 不变的东西

1. **标志永远是青柠绿**（`brand-500`），节点内填充随地色。
2. **品牌条在左上角**：标志 + 字标 `req-kit`（连字符青柠）+ 一个系列胶囊（如 `1.14.0`、`汇报`、`培训`）。
3. **地色**：`canvas`（深）或纸面模式的 `canvas`（浅，用于打印、白底文档插图）。
4. **字体**：Geist + 苹方，标题 800；英文小标题和编号用 `mono`。
5. **结构**：一句主标题、一个视觉主体、一个行动。

## 主题色

| 主题 | 强调 | 用于 |
|---|---|---|
| Lime 青柠（默认） | `campaign-lime` | 版本发布、产品介绍、给领导的汇报 |
| Glacier 冰川 | `campaign-glacier` | 接入外部系统、数据和统计 |
| Nebula 星云 | `campaign-nebula` | AI 能力、模型适配 |
| Signal 信号 | `campaign-signal` | 里程碑、试点成果、数字 |
| Solar 日冕 | `campaign-solar` | 培训、分享会、开放日 |

一张图只用一个主题色；非 Lime 主题时，标志是画面里唯一的青柠绿。和 CMASTER 一起出现时（团队总览），以 CMASTER 的 Ember 为主题色，req-kit 标志保持青柠。

## 标志性图形：放行轨

从标志的对勾流水线衍生的超大图形：一段折线（对勾的长边）从画面右侧或底部出血，线上 2–4 个节点，终点是实心的放行灯（主题强调色），其余空心；线宽 2–3px，强调色 30–50% 不透明度。每张图只放一组，不压字。

## 汇报幻灯片（16:9，1920 × 1080）

- **封面**：极光 + 品牌条 + `display-xl` 标题（关键词渐变）+ 一句副标题 + 汇报人和日期（`caption`）。
- **内容页**：`canvas` 底不加极光；左上 eyebrow + `display` 标题（最多两行）；内容用 Bento 网格（12 列，间距 24px，四周安全边距 128px）；页码右下 `caption` `text-muted`。
- **一页一件事**：标题写结论（"每个关键结论都要有程序能检查的证据"），卡片写依据。
- **图表**：条形用 `data`，重点一条用主题强调色；数字用 `metric`，单位用 `title-sm`。
- **结尾页**：需要的支持或下一步，编号用 `metric` 大数字（这里的编号是真实顺序）。
- **演讲者备注**写成口语，一页 2–4 句。

## 海报与社媒

| 用途 | 尺寸 | 安全边距 | 版式 |
|---|---|---|---|
| 竖版海报 | 1080 × 1920 | 96 | 品牌条 → 标题（约 1/3）→ 视觉主体（真实界面截图卡或步骤轨）→ 3 个数字或 3 个胶囊 → 行动区 |
| 社媒方图 | 1080 × 1080 | 72 | 品牌条 → 标题 → 截图卡右下出血 |
| 群聊卡片 | 1200 × 630 | 64 | 左 7 列品牌条 + 标题 + 一行说明，右 5 列放行轨或一个数字 |

- 海报字号按 1080 宽：`poster-hero` 112/116（最多 3 行，每行 8 个汉字以内）、`poster-lead` 32/48、`poster-metric` 168、`poster-eyebrow` 22、`poster-caption` 22；正文不小于 22px。
- 行动区：一句承诺 → 行动块（主题色底、对应 `on-campaign-*` 字）→ 安装命令或联系方式。当前口号"一句需求，到可验收的功能"，承诺"第一个需求，我们陪你走完"。

## 每个正式版自动生成

正式版发布时由 `scripts/release-media.mjs` 生成一套：竖版海报、群聊卡片、汇报幻灯片（封面 → 这一版带来几项变化 → 每页两项的细节 → 升级须知 → 数字 → 开始使用），版式按本页规则，内容取自 CHANGELOG，数字都是当次核实过的。标题口号写在 `design/releases/<版本>.json`（没有就用版本号）。生成的文件附在 GitHub Release 上，HTML 可以改了再导出。

## 不要

- 不用 emoji、霓虹多色、粒子网络、AI 生成的人物或场景插画。
- 不展示没上线的能力；数字要能核实（测试数、版本数等写明截至哪个版本）。
