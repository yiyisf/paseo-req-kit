# 审查类网页

审查原型并确认方案（`app.html`）、验收清单（`check.html`）、代码审查（`code.html`）是 req-kit 自己的网页，由本机的审查服务提供，在 Paseo 网页里打开，也能在手机浏览器里打开。它们是**做决定的页面**：读者看完要做一个决定，所以三页用同一个骨架。

## 骨架

```
┌──────────── 顶栏 48px（surface-0，底部 border-default）──────────────┐
│ 标志 req-kit · 需求标题 · 代码胶囊（功能目录）        只读/可编辑 · 主题 │
├────────────────────────────────────────────────────────────────────┤
│ 状态横幅（可选）：已通过 / 需要重新评审 / 只读链接 / 流水线正在改       │
├──────────────┬─────────────────────────────────────────────────────┤
│ 侧栏 264px     │ 主区 最宽 920px                                        │
│ surface-1     │ eyebrow → title-lg 标题 → 一句话说明这一页要你做什么     │
│ 目录或文件列表 │ 卡片列表（意见、验收项、改动文件）                         │
├──────────────┴─────────────────────────────────────────────────────┤
│ 决定栏（固定在底部，surface-1 + shadow-float，高 64px）                  │
│ 进度摘要（已看 3/5 · 2 条意见）   次要输入（评审人）   [次要动作] [主按钮] │
└────────────────────────────────────────────────────────────────────┘
```

- 背景 `canvas`，不用极光。默认跟随系统深浅色，顶栏右侧可切换（记在浏览器里）。
- 不加载外网字体（内网常打不开，会让页面等到超时），字体栈直接落到苹方、微软雅黑等系统字体。
- **决定栏**是每页唯一放主按钮的地方：左边一句进度摘要（`body-sm`），右边最多两个按钮，主按钮青柠绿在最右。决定栏里的输入框（评审人、审核人）标签放在输入框左边、同一行，让摘要、输入框和按钮垂直居中对齐。主按钮在条件不满足时禁用，旁边一行 `caption` 说明还差什么（"还有 2 条必须验的没有核对"）。
- 960px 以下侧栏收到主区上方，变成可折叠的一行；400px 宽时决定栏的输入框换行到按钮上方，正文底部留出决定栏的高度。
- 只读链接：顶栏右侧 `badge` "只读"，决定栏换成一行说明"这是只读链接，只能查看"。

## 三页各自的内容

| 页面 | eyebrow | 主区卡片 | 次要动作 | 主按钮 |
|---|---|---|---|---|
| 审查原型 | `PROTOTYPE REVIEW` | 原型预览（`canvas` 底 + 点阵，`radius-xl`），点选区域加青柠描边和编号图钉；右侧意见清单 | 提交修改意见 | 确认方案 |
| 验收清单 | `ACCEPTANCE` | 验收项卡片：编号、标题、前置条件 / 操作 / 预期结果、流水线结论徽章、三个选项"通过 / 不对 / 先不验" | 把它跑起来试用（顶部） | 提交验收 |
| 代码审查 | `CODE REVIEW` | 改动摘要卡、AI 评审意见汇总卡、按文件的差异块，AI 意见和人的意见插在对应行下 | 退回修改（`btn--danger-outline`） | 评审通过 |

## 规则

- **AI 写的和人写的分开。** AI 评审意见卡：`ai-tint` 底，左上 `Sparkles` + "AI 评审" + 编号 `CR-1` + 级别徽章；评审人自己的意见卡：`surface-2` 底、`brand-edge` 1px 描边、"你的意见"。不要用彩色左边框区分。
- **级别**：阻塞 = `status-failed`，重要 = `status-warning`，建议 = `text-secondary`，待核实 = `ai`。级别徽章永远带文字。
- **流水线结论**（验收项、AI 意见的处理结果）：已验证通过 `status-success` + `CircleCheck`；没通过 `status-failed` + `CircleX`；没验证 `text-muted` + `CircleDashed`；已修复 `status-success`；判为不成立 / 决定不修 `text-secondary`。
- **差异块**：`surface-2` 卡，文件头 `surface-3`（文件路径 `code-sm` + `+12 −3`，加号 `diff-added`、减号 `diff-removed`）；新增行 `success-tint` 底，删除行 `failed-tint` 底；行号 `text-muted`、`tabular-nums`；需求文档类文件排在最后，默认折叠。差异块在自己的容器里横向滚动。
- **原型图钉**：24px 圆形，`brand-500` 底、`on-brand` 数字，`shadow-float`；被选中的区域 2px `brand-500` 描边 + `brand-tint` 遮罩。
- **空状态和错误**：用 EmptyState（图标 + 一句结果 + 一句怎么办），例如"没有改动：这个需求的分支和主分支一样"。网络错误写清楚"没保存，网络恢复后会自动重试"。
- **进度自动保存**：顶栏中间一行 `caption`"已自动保存 14:32"，不弹提示。
