# StepTrack

步骤轨：一排编号圆点串起需求走到了哪一步。

- 消费方提供：步骤列表（名称、谁来做、状态 done / now / needs / 空）。
- 圆点 28px：已完成 = 成功色描边 + 对勾；进行中 = 青色 + `glow-run`；等你处理 = 青柠实心 + `on-brand` 数字；未到 = 空心描边。连线到达过的段为成功色。
- 下面两行：步骤名（`title-sm`）、谁来做（`caption`："你""AI""AI · 你确认""需求方"）。
- 用于插件需求详情、首页流程介绍（介绍时不显示完成状态，只把人做决定的步骤点亮）、幻灯片。
- 窄屏横向滚动，不换行。
