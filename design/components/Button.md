# Button

按钮。每页只有一个主按钮（青柠），放在决定栏最右或卡片右下。

- 消费方提供：文字（动词开头，说清楚会发生什么）、可选的 16px Lucide 图标、是否禁用以及禁用原因。
- 变体：`rk-btn--primary`（青柠底 + `on-brand` 字 + `brand-edge` 描边）、默认（`surface-2`）、`rk-btn--ghost`、`rk-btn--danger-outline`（退回修改等不可逆的反向操作）、`rk-btn--cta`（只在首页、海报）。尺寸 `--sm` 28px、默认 36px、`--lg` 44px。
- 禁用时旁边一行 `caption` 写还差什么，或用 `title`。
- 不要：白字青柠底；一个区域里两个主按钮；"确定""提交""OK"。
