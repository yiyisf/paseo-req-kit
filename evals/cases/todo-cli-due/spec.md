# 待办任务支持截止日期和逾期筛选

- 状态：已确认（2026-10-13）
- 档位：标准
- 类型：新需求
- 版本：1
- 格式：req-kit/spec@1
- 需求提出人：评估用例

## 1. 背景与目标

使用者用 todo-cli 记录工作事项，但无法记录截止日期，经常错过期限。

**目标**：添加任务时可以写截止日期；能单独列出已经逾期的任务。

**怎么衡量做成了**：下面的验收标准全部通过。

## 2. 用户与使用场景

| 角色 | 是谁 | 在什么情况下会用到 |
| --- | --- | --- |
| 使用者 | 在终端里记待办的同事 | 每天早上查看今天该做和已经逾期的事 |

## 3. 范围

**本次要做**
- 添加任务时可选的截止日期；列表中显示截止日期；逾期筛选

**本次不做**
- 修改已有任务的截止日期；提醒通知；时间（精确到小时）

## 4. 主流程

1. 使用者执行 `todo add "写周报" --due 2026-10-20`，得到新任务编号。
2. 执行 `todo list`，看到 `1. [ ] 写周报（截止 2026-10-20）`。
3. 某天执行 `todo list --overdue`，只看到截止日期早于今天、且未完成的任务。

## 5. 功能需求与验收标准

### FR-1 添加任务时写截止日期（优先级：必须有）

- **AC-1.1** `todo add 写周报 --due 2026-10-20` 成功，输出新任务编号；`--due` 可以出现在内容之前或之后，不会被当作任务内容的一部分。
- **AC-1.2** 日期必须是 `YYYY-MM-DD` 格式且是真实存在的日期。`--due 2026-13-01`、`--due 2026-02-30`、`--due 明天`、`--due` 后面没有值，都输出 `错误：截止日期格式应为 YYYY-MM-DD`，退出码 1，不保存任务。
- **AC-1.3** 不写 `--due` 时行为与现在相同。

### FR-2 列表显示截止日期（优先级：必须有）

- **AC-2.1** 有截止日期的任务在标题后显示 `（截止 YYYY-MM-DD）`（中文全角括号），例如 `1. [ ] 写周报（截止 2026-10-20）`。没有截止日期的任务显示不变。
- **AC-2.2** `list --all` 同样显示截止日期。

### FR-3 逾期筛选（优先级：必须有）

- **AC-3.1** `todo list --overdue` 只列出未完成、且截止日期早于"今天"的任务；截止日期等于今天的不算逾期；没有截止日期的不算逾期。
- **AC-3.2** "今天"取环境变量 `TODO_TODAY`（`YYYY-MM-DD`）；没有设置时取本机当前日期（本地时区）。
- **AC-3.3** 没有逾期任务时不输出任何内容，退出码 0。

### FR-4 兼容已有数据（优先级：必须有）

- **AC-4.1** 已有的数据文件（任务没有截止日期字段）可以正常读取、列出、完成，不报错。
- **AC-4.2** 现有测试全部继续通过。
