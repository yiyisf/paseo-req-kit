# 0001 步骤 agent 挂在发起的对话下

- 状态：已采纳（[0018](0018-own-worktree-option.md) 增加了一种可选方式：步骤放在为需求新建的工作区中，仍挂在对话下，对话目录不变）

## 背景

Paseo 在创建子 agent 时，如果传了 parent，会使用 parent 的工作目录而不是传入的 cwd。早期版本在两者不一致时改为创建独立 agent，结果步骤的产物写到了别处。

## 决定

步骤 agent 一律作为子 agent 挂在发起的对话下；仓库目录就是这个对话的工作目录。启动前核对两者，不一致时拒绝启动；创建后再核对 agent 的工作目录，不对就归档并报错。

## 影响

使用者在对话的子 agent 列表里就能看到每一步；不会出现产物写错目录的情况。代价是必须在需求所在项目的对话中发起。
