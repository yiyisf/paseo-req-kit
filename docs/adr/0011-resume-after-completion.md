# 0011 完成后修改 spec 可以继续开发

- 状态：已采纳

## 背景

修改需求、验收发现问题时，流水线往往已经完成。原来的规则是"已完成的流水线不能 --resume，只能 --restart"，而 --restart 会丢掉运行记录，也不是使用者想表达的意思。

## 决定

流水线已完成、且 spec.md 在完成后被修改过时，`--resume` 从方案设计重新开始（第 N+1 次尝试），沿用原来的发起对话和分支；spec 没有改过时仍然拒绝，并说明先更新 spec。

## 影响

"修改需求"和"验收"手册可以统一用"继续"命令；每次重开都有 changes.md 中的记录可查。
