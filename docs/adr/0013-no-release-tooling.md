# 0013 发布不使用 changesets 等工具

- 状态：已采纳（取代设计方案中"由 changesets 维护 CHANGELOG"的计划）

## 背景

设计方案计划用 changesets 维护版本号和 CHANGELOG。req-kit 是单一包、发布频率低，CHANGELOG 的主要读者是使用者和安装者，需要"使用者会看到的变化"和"升级须知"这样的结构，工具生成的条目还要人工改写。

## 决定

版本号和 CHANGELOG 由维护者按 [维护者指南](../guide/维护者指南.md) 的发布流程手工维护；标签不带 `v` 前缀。

## 影响

少一个开发依赖。需要维护者在每次发布时认真写 CHANGELOG；发布流程中的验证步骤由指南约束。
